# Todo-List App
## Instalation Instructions (the way I installed this App)
1.  I creaed an empty repository in Github and copied its url
2.  Then I navigated to the file that I wanted to put it in and moved to git bash
3. In git bash, I cloned the repository "git clone https://github.com/Dana-codeExplorer/todo-list.git"
4. Adding react/vite is the next step "npx create-vite@latest --template ."
5. After that I installed it- "npm install" 
6. "npm run dev" starts the server.
7. Coping the url and putting it into the browser, opens the browser view of the project
8. In the terminal, I added these folders  "git add ."
9. My inital commit came next "git commit -m "inital commit"
10. "git push -u origin main" is the command to get the changes back into the external repository in Github
11. In the terminal I typed, "git checkout -b lesson-01-setup" to create a new branch and to swith to it .
12.  I followed class insructin to clear out all uneccesary code.
13. I replaced that code in the App.jsx file with an H1 and an unordered list 
14. The ul has a code block that maps through the items in a todo-list with a todo li item and a key (prop) of todo id
15.  I went to the browser and check the console for errors  and checked the terminal for problems. there were none listed.
16.  Once again , I did a "git add " command and a another commit "git commmit -m "setup"
17. In Github I clicked "pull and compare" ,selected main and then selected the branch and clicked "create pull request " The pull request was made.
18. If cleared to merge, You click "merge" and "confirm merge"
19. the Last step is to return to the terminal, switch to main and type "git pull" to bring those changes back to your local main branch.  Then that branch can be deleted.
